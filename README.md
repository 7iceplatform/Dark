# Alliance Watch — Telegram Mini App

Статическая панель для R4 альянса Last Asylum. Она читает публичный JSON API альянса и показывает игроков, которым нужна проверка.

## Что анализируется

- недельная активность в альянсе;
- прирост мощности за 7 дней;
- дата вступления;
- пропущенные значения в публичном источнике.

В API нет последнего времени входа в игру. Поэтому приложение не утверждает, что игрок офлайн: оно помечает низкую активность в альянсе.

## Логика статусов

- **Критично**: участник состоит 7+ дней, активность не выше 200 и рост не выше 3 млн.
- **Проверить**: участник состоит 7+ дней, и хотя бы один из этих показателей ниже порога.
- **Новичок**: в альянсе меньше 7 дней; автоматически не попадает в кандидаты на исключение.
- **Нет данных**: API не вернул активность или дату вступления.

Пороги задаются в функции `getStatus` файла `app.js`.

## Публикация в Telegram

1. Разместите эти четыре файла на HTTPS-хостинге.
2. В BotFather создайте или откройте бота и укажите URL Mini App.
3. Добавьте кнопку Menu Button или inline-кнопку, которая открывает URL приложения.

Приложение не требует токена бота и не выполняет действий в игре.

## Ограничение CORS

Фронтенд получает данные напрямую с `https://lastasylum.gg/api/alliance/67172519`. Если выбранный хостинг блокируется политикой CORS, добавьте небольшой серверный прокси, который запрашивает этот публичный API и возвращает ответ приложению. Не передавайте через прокси пользовательские токены или игровые данные.
