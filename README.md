# Alliance Watch — Telegram Mini App

Панель для R4 альянса Last Asylum, рассчитанная на GitHub Pages. GitHub Actions получает публичный JSON API раз в 15 минут и публикует статический снимок вместе с приложением.

## Что анализируется

- недельная активность в альянсе;
- прирост мощности за 7 дней;
- дата вступления;
- пропущенные значения в публичном источнике.

В API нет последнего времени входа в игру. Поэтому приложение не утверждает, что игрок офлайн: оно помечает низкую активность в альянсе.

## Логика статусов

- **Критично**: участник состоит 7+ дней, активность не выше 200 и рост не выше 3 млн.
- **Проверить**: участник состоит 7+ дней, и хотя бы один из этих показателей ниже порога.
- **Новичок**: в альянсе меньше 7 дней; автоматически не попадает в кандидаты на исключение.
- **Нет данных**: API не вернул активность или дату вступления.

Пороги задаются в функции `getStatus` файла `app.js`.

## Публикация на GitHub Pages и в Telegram

1. Создайте репозиторий GitHub и загрузите в него проект в ветку `main`.
2. В **Settings → Actions → General** разрешите рабочим процессам доступ **Read and write permissions**.
3. В разделе **Actions** вручную запустите workflow **Update alliance data**. Он добавит первый файл `data/alliance.json`.
4. В **Settings → Pages** выберите источник **GitHub Actions**. Workflow **Deploy GitHub Pages** опубликует сайт.
5. Полученный адрес GitHub Pages укажите в BotFather как URL Mini App.

Приложение не требует токена бота и не выполняет действий в игре. GitHub Actions сохраняет только общедоступный снимок альянса.

## Почему используется снимок данных

Браузер Telegram не может обращаться к `lastasylum.gg` напрямую: API не разрешает такой запрос политикой CORS. GitHub Actions загружает публичные данные на стороне GitHub, а приложение читает файл `data/alliance.json` с собственного домена. Поэтому CORS и ошибка 404 не возникают.

Данные обновляются примерно раз в 15 минут. GitHub может задерживать запланированные запуски, поэтому это не режим реального времени.
